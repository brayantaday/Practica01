## Descripción

Aplicación web de gestión de empleados desarrollada con el stack MEAN (MongoDB, Express, Angular, Node.js). Permite crear, listar, editar y eliminar empleados con una interfaz moderna y responsiva.

## Estructura del Proyecto

```
mean_empleados/
	backend/    # API REST Node.js + Express + MongoDB
	frontend/   # Aplicación Angular
```

## Backend
- Express, Mongoose, CORS, Morgan, Dotenv
- CRUD de empleados
- Conexión a MongoDB local o Atlas

### Comandos útiles

```bash
cd mean_empleados/backend
npm install
npm run dev
```

## Frontend
- Angular 17 standalone
- Bootswatch + Bootstrap para UI
- CRUD visual de empleados

### Comandos útiles

```bash
cd mean_empleados/frontend
npm install
ng serve
```
